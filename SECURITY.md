# Security

The OpenCode password is a shell on the host. Anyone who has the URL and the password, or a live pairing link, can run tools as the service user.

Read [docs/security.md](docs/security.md) before you point this at a machine that holds anything you care about.

## Reporting

Please use [GitHub private vulnerability reporting](https://github.com/joe-broadhead/opencode-vps/security) for this repository.

Do not open a public issue that contains a server password, a pairing link, a QR screenshot, a provider key, or a live tailnet hostname. A description of the bug is enough.
